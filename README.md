# Tactical Arena

Tactical Arena is a dependency-free browser arena shooter with a colorful pseudo-3D raycast renderer, animated cartoon bots, two weapons, generated audio, radar, score persistence, and a complete round loop.

## Play locally

```bash
python3 -m http.server 4789 --bind 127.0.0.1
```

Open `http://127.0.0.1:4789`.

## Controls

- `WASD`: move
- `Space`: jump
- Mouse: aim
- Left click: shoot
- `R`: reload
- `1` / `2`: switch weapons
- `Esc`: pause or release pointer lock

The game uses original geometric artwork and generated Web Audio effects. No third-party game assets or copyrighted franchise material are included.
